# Valery Sofia — Personal Portfolio

Bilingual personal portfolio for a fourth-semester Systems Engineering student. The site uses HTML, CSS, and JavaScript and includes Home, About, Skills, Resume, Projects, and Contact sections.

## Files
- `index.html`: page structure
- `style.css`: visual design and responsive layout
- `script.js`: Spanish/English text and language switcher
- `images/`: local SVG illustrations used in the page
- `NOTES.md`: English reflection for the assignment

## Publish with GitHub Pages
1. Upload these files and folders to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. Wait for GitHub Pages to publish, then test the page on desktop and mobile.
5. Make at least two commits documenting your changes.
